# Security policy

The latest `master` revision is supported during the initial 0.1 development series. Install only reviewed revisions and keep Alliance Auth and dependencies current.

Please report vulnerabilities through the repository's **Security → Report a vulnerability** private reporting feature. Include reproduction steps, affected revisions and impact. Do not post wallet tokens, SSO credentials, character account information or unredacted private wallet entries in public issues.

Important boundaries include manager/admin separation, renters' invoice isolation, concurrent bidding/settlement, SSO token ownership, corporation master-wallet access and duplicate-payment protection. Test settings, demo data and screenshots contain no real wallet credentials and must never be used in production.
